# Masters Project - Plasticity in deep reinforcement learning

The work "Understanding Plasticity in Neural Networks" is one of the seminal works in the study of plasticity in the context of deep reinforcement learning. As the original authors have not provided a code base for the community to reproduce the experiments and results, this work is an effort to reproduce the data and experiments created by the team.


This work has been submitted to Uni-Freiburg as part of my Masters project, but any contribution and points are very welcome and appreciated.

The goal of this project is to study and showcase the problems of neural networks losing their plasticity especially in the Deep RL context in a theoretical approach.

In this project we do a literature study on the methods that have been proposed to cause and relieve the issue of plasticity loss in neural networks.
